Sistemas de Numeración

➗
De decimal a otra base

Divide el número entre la base de destino repetidamente y anota los residuos. El resultado se lee de abajo hacia arriba.

  • 13 ÷ 2 = 6, residuo 1
  • 6 ÷ 2 = 3, residuo 0
  • 3 ÷ 2 = 1, residuo 1
  • 1 ÷ 2 = 0, residuo 1 → 1101

✖️
De otra base a decimal

Multiplica cada dígito por la base elevada a su posición (empezando en 0 por la derecha) y suma.

  • 1101₂ = 1×2³ + 1×2² + 0×2¹ + 1×2⁰
  • = 8 + 4 + 0 + 1 = 13

🔤
Dígitos mayores que 9

A partir de la base 11 se usan letras: A = 10, B = 11, ..., F = 15, ..., Z = 35.

  • Hexadecimal: 0-9 y A-F
  • Base 36: 0-9 y A-Z
