¿Cómo se Convierte?

÷
Fracción a decimal

Se divide el numerador entre el denominador.

  • 3/4 = 3 ÷ 4 = 0.75 (exacto)
  • 2/3 = 0.666... = 0.(6) (periódico puro)
  • 5/6 = 0.8333... = 0.8(3) (periódico mixto)

.
Decimal exacto a fracción

Se escribe el número sin punto sobre 1 seguido de tantos ceros como decimales tenga, y se simplifica.

  • 0.75 = 75/100 = 3/4
  • 1.2 = 12/10 = 6/5

🔁
Decimal periódico a fracción

Numerador: el número completo menos la parte no periódica. Denominador: tantos 9 como cifras periódicas y tantos 0 como cifras no periódicas.

  • 0.(3) = 3/9 = 1/3
  • 0.1(6) = (16 - 1)/90 = 15/90 = 1/6
